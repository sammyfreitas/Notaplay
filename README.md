# NotaPlay — Mini Piano V3

Mini piano educativo em HTML, CSS e JavaScript puro.

## Novidades da V3
- Biblioteca ampliada para 50 músicas, melodias tradicionais e exercícios.
- Filtros por dificuldade, origem e tipo.
- Partitura simplificada dividida em frases musicais, sem rolagem horizontal gigante.
- Modos Livre, Aprender, Ouvir e Desafio.
- Notas em números, Dó–Si e C–B.
- Mouse/touch, números 1–7 e teclado CVBNM,.
- Tema claro/escuro.
- Redes sociais oficiais de Anthony Freitas atualizadas.
- Sons gerados pela Web Audio API.

## Observação
A biblioteca prioriza melodias tradicionais, domínio público e exercícios originais. A arquitetura está pronta para receber outras músicas e categorias.

Abra `index.html` ou use Live Server.
